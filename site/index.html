marcos/helix

A personal fork of the Helix editor

Helix, customized for the way I work.

This is a fork of the Helix editor, not a new editor. It's upstream Helix, kept in sync, plus a few features I built for my day to day as a software engineer: a Claude Code popup, side by side git diffs, a commit log and a file explorer panel.

See what's added Full docs (FORK.md)

Read this first

  • It's a fork, not a new editor. Everything that isn't listed on this page is plain Helix and works exactly as described in the Helix documentation.
  • It's a personal build. It grows with what I need in my daily work, not with a roadmap. Features are added when I need them, and shaped by how I use them.
  • It's not necessarily stable. I can't promise there are no bugs, and there's no support guarantee.
  • There's no release schedule. Two features might land in one day, and then nothing for a month.
  • That said, I use it every day at work. It's my main editor, so bugs that get in the way are found and fixed quickly. Frequent breakage isn't expected.
  • Much of it is written with AI assistance. Since it's a personal build, I use AI tools heavily to move faster on the fork's changes.

What the fork adds

These features won't be accepted upstream, so they live here. Each one is documented in detail, with its limitations, in FORK.md.

Claude Code popup

Runs Claude Code in a terminal embedded in a popup, with the current file, line and selection as context. Sessions keep running in the background when the popup is hidden.

space itoggle the popup
space Ipick a session
:claude …new session with a prompt

Side by side git diff

A file's HEAD version next to its current contents, with syntax highlighting, aligned changed lines and word level highlights. Unsaved buffer changes are included.

space =diff of the current file
C-gdiff of the selected file in space g
n Nnext / previous hunk

Git commit log

Browse the commits of HEAD, list the files a commit changed, and open the side by side diff of any of them against the commit's parent.

space lcommit picker
Enterfiles of the commit, then the diff
q Escstep back

File explorer side panel

A file tree on the left of the editor, with icons, git ignored files dimmed, and the current buffer revealed as you move around. Create, rename, move and delete from it.

space Eopen / focus / close
a r x dcreate, rename, move, delete
C-w h lmove between panel and editor

Staged files in space g

Upstream's changed files picker only lists unstaged changes. Here it lists every change compared to HEAD, like git status: staged, unstaged, added and renamed.

space gchanged files picker

Install

Built from source, the same way as upstream Helix. You need a Rust toolchain. The default branch, marcos, is the fork's version. 

git clone https://github.com/marcos-venicius/helix
cd helix
cargo install --path helix-term --locked

This installs the hx binary, replacing an existing Helix install. Helix also needs its runtime files (themes, grammars, queries): see configuring Helix's runtime files. The Claude Code popup needs the claude CLI in your PATH.

Found a bug in one of the fork's features? Please open an issue on the fork, not upstream. Bugs in plain Helix belong upstream.
